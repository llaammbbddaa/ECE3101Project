# **Project Proposal**

**USB Gamecube Controller**

*Group: 8*

*Team Members: John Sarrouf, Nathaniel Nevarez, Tai Vuong, Melissa Lorenzo-Mendez*

**Project Summary:**

The goal for this project is to remake the highly successful *Gamecube* controller, while also adding some much needed features. (See below for the controller image.)

![gamecube controller image](gamecubecontroller.jpg)

In terms of the specifics, we will likely be using an Arduino Nano to work with the small space that we will have within the controller.

Additional Specifications:  
*Hardware:*

- Arduino Nano  
- Analog joysticks  
- Buttons and triggers  
- Vibration motor  
- Custom PCB  
- USB connection  
- 3D-printed enclosure

*Software:*

- Analog input processing  
- Snapback filtering  
- Stick-angle processing  
- Vibration control  
- Macro functionality

**Project Objectives / Scope:**

The controller has three shoulder buttons, two of which being analog, five / six face buttons, and two movement sticks. The focus behind upgrading the controller is to improve consistency when playing video games, as some of them require highly technical and precise play.

In terms of specific things we would like to improve on:

- Controller “Notches”  
  - Some games require you to input very specific controller stick angles for optimal play, we would like to make this easier to pull off. (In reality, people often create literal notches in the plastic, which can often be inaccurate and damage the controller housing.)  
- Controller Vibrations  
  - Some people prefer to have their controller vibrate, and some don’t, it would be nice to be able to have that as a togglable option for users.  
- Macros  
  - Some games require exceptionally precise inputs to be done in fast succession, it would be nice to add the ability to just press a button and have it perform the sequence of inputs for you.  
- Stick “Snap Back”  
  - If the stick is released from a far angle, it can sometimes “snap back” in the opposite direction, creating unintentional input and movement. Eliminating this isn’t very difficult, but can be risky considering you have to resolder components on the controller.  
- Repairability  
  - The company that made this controller doesn’t really manufacture them as much anymore, and the second hand and knockoff market is not ideal either. Making a controller that can be configured and repaired easily is a high priority.

Limitations:

- Wireless Capabilities  
  - Simply as a result of the goal, we will not be making any attempts to make this controller wireless. This is entirely because it will add latency to the user’s inputs, which is not ideal for serious play.  
- Tournament Legality  
  - Because this is a heavily modified controller, it is definitely not legal to use it to play in an actual tournament.  
- Budget  
  - This will primarily be made with things that we already have from previous projects as well as whatever we can get for free reasonably.

**Project Deliverables:**

At the end of this project, we would like to have a complete and functional USB-compatible Gamecube controller. With the modifications listed above, it will allow for greater consistency and ease of play.

It will have its own 3D-printed enclosure as well as a custom made PCB.
